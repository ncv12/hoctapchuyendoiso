Hướng Dẫn Đăng Lên GitHub Pages

1
Tạo tài khoản GitHub Truy cập GitHub.com, đăng ký tài khoản. Chọn **"New repository"**, đặt tên (VD: `game-lat-o`).
2
Tải file index.html lên Lưu file HTML này với tên đúng là index.html. Chọn **Add file -> Upload files**, kéo thả file vào rồi chọn **Commit changes**.
3
Bật GitHub Pages Vào **Settings** -> **Pages**. Ở mục Branch chọn **main** (hoặc master) rồi chọn **Save**.
4
Nhận link game Sau 1-2 phút, GitHub sẽ xuất link web chơi game chính thức cho iPad và máy tính!
